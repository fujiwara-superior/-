# 株式会社聖建様 ご提案資料

建設業の特別教育をオンラインで提供するプラットフォームの構築提案（新規事業）。

## 成果物

- `聖建様_特別教育オンラインプラットフォーム_ご提案.pptx` — 提案資料（全21ページ、発表者ノート付き）
- `聖建様_特別教育オンラインプラットフォーム_ご提案.pdf` — 同上のPDF版（先方へのメール送付用）
- `build.js` — 資料を生成するスクリプト（pptxgenjs）

## 再生成

```
npm install pptxgenjs
node deck/build.js
```
