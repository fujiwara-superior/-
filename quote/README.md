### 行を挿入するときの注意

`insert_rows()` は**結合セルの範囲を追従させません**。見出し行など結合のある
シートに行を挿入したら、`unmerge_cells` / `merge_cells` で張り直してください。
今回 03_見積明細 で小計行が結合に飲み込まれて空になる不具合が起きました。
数式も追従しないため、挿入後は SUM の範囲と他シートからの参照を必ず確認します。

### 改行についての注意

セル内で改行したいときは、**全角スペースを並べず、Alt+Enter（Macは Option+Command+Enter）で
実際の改行を入れてください。**

スペースでの折り返しは Excel の画面上ではそれらしく見えますが、PDF に書き出すと
フォントの幅が変わるため位置がずれ、文の途中から右端に飛んだように表示されます。
今回はこれで「登録時の本人確認と受講」だけが1行目の右端へ離れていました。

## 角印

**押印済みです。** 藤原が Excel 上で貼り付けた画像を `quote/seal.png` として保管し、
見積書の発行者ブロックの右に、表の右端とそろえて配置しています。

用紙上の位置は **左16.00cm・上4.35cm・2.00cm角**。社名「株式会社スペリオル」の末尾と
住所の右端に重なる、角印として一般的な位置です。

位置とサイズは `finalize.py` の `SEAL_X_CM / SEAL_Y_CM / SEAL_CM` で調整します。
これは**シート座標**（A1の左上を原点とするcm）です。印刷時に約0.82倍へ縮むため、

```
用紙上のcm = 1.083 + 0.82 × SEAL_X_CM     （縦は 1.014 + 0.82 × SEAL_Y_CM）
```

という関係になります。`make_pdf.py` が実際の用紙上の位置を毎回表示するので、
列幅を変えて位置がずれたらそこで気づけます。
