## 角印

**押印済みです。** 藤原が Excel 上で貼り付けた画像を `quote/seal.png` として保管し、
見積書の発行者ブロックの右に、表の右端とそろえて配置しています。

用紙上の位置は **左17.92cm・上5.10cm・2.00cm角**。住所・TEL・登録番号・担当のどの行にも
かかりません（元の位置だと住所の「3-18-10」に重なっていたため移動しました）。

位置とサイズは `finalize.py` の `SEAL_X_CM / SEAL_Y_CM / SEAL_CM` で調整します。
これは**シート座標**（A1の左上を原点とするcm）です。印刷時に約0.82倍へ縮むため、

```
用紙上のcm = 1.083 + 0.82 × SEAL_X_CM     （縦は 1.014 + 0.82 × SEAL_Y_CM）
```

という関係になります。`make_pdf.py` が実際の用紙上の位置を毎回表示するので、
列幅を変えて位置がずれたらそこで気づけます。
