# 株式会社聖建様 概算見積書・注文書

## 成果物

- `聖建様_概算見積書・注文書.xlsx` — 見積・注文の一式（全5シート・数式連動）
- `聖建様_概算見積書.pdf` — 見積書 1ページ（提出用）
- `聖建様_注文書.pdf` — 注文書 1ページ（提出用）
- `build_quote.py` — 生成スクリプト

## シート構成

| シート | 内容 |
|---|---|
| 01_見積書 | 鑑（表紙）。合計・条件・フェーズ別内訳 |
| 02_見積明細 | フェーズ別の明細。人日単価と人日が編集可能 |
| 03_教材科目 | 10科目の一覧。単価とフェーズ割当が編集可能 |
| 04_注文書 | 発注フェーズを選ぶと金額が自動計算される |
| 05_前提条件 | 含むもの／含まないもの／責任分担／金額の前提 |

## 編集できるセル（黄色・青文字）

- `02_見積明細!C4` 人日単価（既定 60,000円）
- `02_見積明細!D列` 各項目の人日
- `02_見積明細` 調整額・消費税率
- `03_教材科目!C4` 教材制作単価（既定 300,000円／科目・聖建様ご指定）
- `03_教材科目!E列` 各科目の発注フェーズ（1〜3）
- `04_注文書!D列` 発注するフェーズのフラグ
- 見積番号・発行日・有効期限・発行者情報（住所／TEL／登録番号）

## 金額の根拠

システム開発の範囲は次の2つの設計書に記載された機能を対象とし、機能要件から人日を積み上げています。

1. 特別教育 eラーニング 本人確認・受講確認システム 詳細設計書 rev.1（2026-09-05）
   → `design/聖建様_本人確認システム設計書.pdf`
2. アーク溶接等特別教育 配信システム基本設計書 1.1（2026-09-05）

教材制作費は聖建様よりご指定の 1科目 300,000円。科目は「建設業向けeラーニング 商品化優先順位」の10科目。
