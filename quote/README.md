## ベースファイル

`聖建様_概算見積書・注文書.xlsx` が**唯一の原本**です。
藤原が Excel 上で直接編集されたブックをそのまま引き継いでいます。
以降の文言修正は Excel で直接行ってください。生成スクリプトはもうありません。

| スクリプト | 役割 |
|---|---|
| `finalize.py` | 印刷設定（A4・1ページ収め）の適用と、角印の配置 |
| `make_pdf.py` | 提出用3点＋社内用のPDF書き出し |

```
python3 quote/finalize.py [角印画像のパス]   # 角印を入れる／印刷設定を直す
python3 quote/make_pdf.py                    # PDFを作り直す
```

`finalize.py` に画像パスを渡すと `quote/seal.png` に保存され、以降は引数なしでも押印されます。
